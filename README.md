# Bocchi Fan — APK (privado)

Repositorio privado solo para guardar los instaladores (APK) de **Bocchi Fan**,
la app de fans de *Bocchi the Rock!*.

- Código fuente: https://github.com/ItsThemassii/AppBocchiTheRock-
- Los APK están en **Releases** (incluyen música y GIFs con derechos de autor:
  por eso este repositorio es privado y solo para uso personal).

## Instalar en un celular
1. Inicia sesión en GitHub desde el navegador del celular.
2. Entra en **Releases** y descarga el `.apk` de la versión más nueva.
3. Ábrelo y permite "instalar apps desconocidas" cuando Android lo pida.
